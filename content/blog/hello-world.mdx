社交媒体很热闹，但热闹是别人的。写完一条动态，它在时间线上活不过一天。

所以我想要一个自己的角落 —— 不追热点、不做数据、不需要谁点赞。就是一个安静的地方，把想说的话放进去，隔很久回来看，还在原地。

## 我想要它是什么样子

我列了三条，只有三条：

1. **打开要快**。慢的网站没人会读第二次。
2. **看着要舒服**。柔和的颜色、够大的字、不刺眼的对比。
3. **写起来要轻松**。想写的时候新建一个文件就能开始，不用登录任何后台。

第三条最重要。工具一旦有摩擦，人就会拖延。

## 于是它变成了这样

写一篇文章的完整流程，是这样的：

```bash
# 1. 新建文件
content/blog/my-new-post.mdx

# 2. 写完保存，推上去
git add . && git commit -m "新文章" && git push
```

没有第三步。构建时文章会被静态生成成 HTML，访问者拿到的是已经渲染好的页面。

<Note type="tip">
  所有文章都放在 `content/blog/` 里，就是普通的 Markdown 文件。哪天我不想用这套系统了，把文件夹拷走就行 —— 内容永远是我自己的。
</Note>

## 关于氛围

配色参考了偶像大师系列的舞台灯光：粉色、紫色、一点点天蓝，背景是柔和的渐变加上会呼吸的光晕。

星光是纯 CSS 做的，没有用 Canvas，也没有粒子引擎 —— 一个 `@keyframes` 加上几十个小圆点就够了。做氛围不该以性能为代价。

> 灯光亮起的前三秒，是我最喜欢的时刻。
> 什么都还没发生，但一切都即将发生。

## 接下来

想写的东西已经攒了一堆：读源码的笔记、听了很多遍的歌、看过的现场。

慢慢来吧。这里不催更，也不需要日更。

有人读到这里的话 —— 谢谢你，欢迎常来。
